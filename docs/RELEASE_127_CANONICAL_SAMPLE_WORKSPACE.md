# AAIQ Release 127 — Canonical Sample Workspace

## Outcome

Release 127 replaces the confusing two-property active pilot with one complete, protected sample workspace. Existing Wyndham Garden and Days Inn records are preserved in archived scope and can be recovered; activation does not delete them.

The sample is the single reference implementation that can be tested, edited through governed controls, and cloned into a new real property.

## Included working sample data

- One hotel identity with a 105-room asset tree and common operational spaces.
- General manager, front-desk supervisor and associate, housekeeping supervisor and attendant, maintenance manager and technician, inventory, compliance, and food-and-beverage roles.
- Eighteen clickable Digital Employee roles with persistent sessions, multilingual text/voice intake, property-scoped reads, approval boundaries, and audit traces.
- Inventory items, property vendor, count locations, and governed photo inventory proposals.
- Cash source rows, physical custody session, independent manager verification path, and variance handling.
- Hiring requisition, job-description/channel drafts, role access blueprint, onboarding locker, corrective-document, and separation workflows.
- Property-scoped Master Inbox conversations and channel configuration.
- Website Factory sample project, twenty hospitality templates, generated property descriptions, approval-controlled revisions, and private preview.
- Review, growth, OTA, workforce, reporting, compliance, housekeeping, maintenance, and video evidence records isolated to the canonical sample property.

## Human boundaries

AAIQ never invents credentials, room facts, employees, money, external-provider results, legal approvals, physical inspection results, or public publication evidence. These remain explicit human/provider inputs. Financial posting, bank deposit, public publishing, surveillance actions, and irreversible configuration changes remain approval-controlled.
