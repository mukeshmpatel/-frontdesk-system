# AAIQ Enterprise Pilot — Release 123 (Rebuilt)

## Provenance

Release 123 was reconstructed additively from the preserved, verified Release 117 archive after the original Release 123 workspace artifact was removed by workspace maintenance. Release 117 and every earlier ZIP remain unchanged. No HNE core repository or GitHub repository was accessed or modified.

## Restored slices

### Release 118 — Workforce lifecycle and access locker

- Property-scoped job requisitions, onboarding cases, access requirements, physical-property custody and separation preparation.
- Termination remains a human decision. The system can prepare and track revocation and return work after authorization.

### Release 119 — Cash and check custody

- Shift cash sessions, denomination counts, exact deterministic variance, check evidence and manager drop verification.
- Posting and financial movement remain drafts until authorized.

### Release 120 — Governed report and attachment ingestion

- Private originals, SHA-256 deduplication, schema-versioned extraction, validation and idempotent downstream action drafts.
- Supports email attachments and manual upload without inventing report facts.

### Release 121 — Energy and guest-room experience plans

- Provider/device registry, disabled-by-default energy policies, evidence-backed action proposals, rollback data, TV message drafts and savings evidence.
- No thermostat, switch or television action is enabled until a provider connection, property mapping, approval policy and rollback test pass.

### Release 122 — Presence and reputation governance

- Property-scoped geofence/time/media evidence with liveness and 1:1 face-verification result fields.
- Missing private media storage invokes a manager-observed alternative. Biometric failure never causes automatic pay, discipline or termination action.
- Guest recovery journeys and contact drafts preserve the same public-review opportunity regardless of score.

### Release 123 — Event Workforce

- New canonical `AAIQ Event Workforce` module, API and responsive UI.
- Digital Wedding Planner, Digital Event Manager and Digital Banquet Coordinator.
- One inquiry creates a property-scoped portfolio, five operational tasks, a discovery document draft, an acknowledgment draft and an audit event.
- Pricing, contracts, deposits, vendor commitments and external sends remain approval-controlled.
